# Cryptology Project

This is a toy project combining three algorithms to "exchange" emails securely.

1. Chacha20 for symmetric encryption of messages.
2. DH-KEM for generating the chacha20 key securely between the clients.
3. Rabin signature for verifying the signature of the message.
